# Shiftt status

The status page at [status.shiftt.io](https://status.shiftt.io), run by
[Upptime](https://upptime.js.org) on GitHub Actions and Pages.

This repository holds health checks of Shiftt's public endpoints and their history. It holds no
product code, no credentials and no data. The checks are listed in `.upptimerc.yml`.
